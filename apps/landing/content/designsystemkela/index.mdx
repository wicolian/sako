## Animation Patterns & CSS Classes

### Custom CSS Animations (globals.css)
- `animate-fade-in`: Staggered content reveal (0.8s ease-out)
- `animate-float`: Floating motion (6s infinite)
- `animate-pulse-slow`: Slow pulse (4s cubic-bezier)
- `animate-spin-slow`: Very slow rotation (20s linear)
- `animate-eyebrow`: Badge reveal animation
- `animate-slide-in-right`: Right slide entrance
- `animate-slide-up-fade`: Upward slide with fade
- `animate-slide-up`: Simple upward slide
- `animate-scan`: Progress bar scanning effect
- `animate-cursor-move`: Cursor movement simulation
- `animate-launch`: Launch/check animation
- `animate-type`: Typing effect (3s steps)
- `animate-blink`: Blinking cursor effect

### Magic UI Animation Library
- `animate-shiny-text`: Text shimmer effect
- `animate-shimmer-slide`: Sliding shimmer
- `animate-spin-around`: 3D rotation
- `animate-rainbow`: Rainbow gradient cycle
- `animate-marquee`: Horizontal scrolling text
- `animate-marquee-vertical`: Vertical scrolling
- `animate-gradient`: Background gradient shift
- `animate-blink-cursor`: Cursor blinking
- `animate-grid`: Grid pattern animation
- `animate-shine`: Shine effect

## Maintenance Guidelines

### Adding New Components
1. Add to appropriate component index file (`blocks/index.ts` or `landing/index.ts`)
2. Document in this design system page
3. Use existing design tokens from `src/lib/design-tokens.ts`
4. Follow established animation patterns

### Animation Best Practices
1. Use staggered delays for content reveals (100ms increments)
2. Prefer CSS animations over JavaScript for performance
3. Use `animate-fade-in` for initial page loads
4. Reserve complex animations for high-impact sections only
5. Test animations on mobile devices

### Copy + Animation Integration
- **Typing animations:** Use for technical/process content (file names, commands)
- **Countdown timers:** Use for SLA/delivery time demonstrations
- **Progress bars:** Use for workflow status visualization
- **Flip words:** Use for benefit/value proposition rotation
- **Gradient text:** Use sparingly for section headers and highlights
