# Contributing

Thanks for wanting to help.

- Open a pull request against `main`. Direct pushes to `main` are blocked.
- Every PR is reviewed by the owner (@wicolian) before it is merged.
- Keep each PR to one change. Say what it does and how you checked it.
- Never commit secrets, `.env` files, or real customer data. CI scans every PR.
- This project is not actively maintained, so reviews can be slow.
